morse code is a language more popular in war times that consists of dots (.) and dashes (-) and by arranging them in a specific way you can create sentences.

The original American Morse code was used primarily in the United States, while International Morse Code, standardized in 1851, became the global standard. International Morse Code includes the 26 Latin letters, numerals 0–9, and some punctuation, and it is still used today in amateur radio, aviation, accessibility technology, and emergency signalling.
